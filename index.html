Brand

  • Verified claimsOnly VERIFIED Claims-Register numbers may appear externally, cited in scope.
  • LogoDot-density sphere — never rebuild the dots. White mark on dark/coral; never on mid-tones.
  • PhotographyReal people in real retail contexts — documentary, natural light, warm grade. No stock clichés, no rendered people.
  • VoiceConfident and precise, never hype. The authority of the data.

Colors

  • Verified contrast pairingsBody text is Ink. Text on coral fills is white (brand rule).
  • Primary — CoralThe brand. Fills, CTAs, accents. Display-only — never small text.
  • Regular — NeutralsWarm neutrals, never cold white or pure black. All text is Ink.
  • SecondaryMarketing collateral. Aqua doubles as the semantic signal color.
  • Opacity tintsAll UI tints derive from the eight via opacity — no other named colors exist.

Gradients

  • Extended gradient huesAllowed ONLY inside gradients — never as swatches, UI, or text.
  • Six coded gradientsEmber · Depth · Current · Bloom · Glow · Night — section backgrounds via .sig-grad-<name>.

Structure

  • Line-grid substrate32px hairline coordinate grid with technical framing. Lines are neutral — never coral.
  • Motion — pulses on the gridLight travels along grid lines. Slow, sparse, purposeful. Particle meshes are rejected.
  • Radii & hairlines6px chips · 8px buttons/inputs · 12–16px cards. Hairline borders everywhere.
  • Spacing scale8px rhythm; 32px is the grid unit.

Icons

  • Icon rulesTwo colors only · 48px floor · accent marks the subject.
  • Icon set151 duotone icons across 13 categories — ink structure, coral subject.

Type

  • Display scaleNHG Display Pro 600, tracking −0.02em, from 28px up.
  • One typefaceNeue Haas Grotesk only — hierarchy from weight and size. Inter is the approved web stand-in.
  • Text & dataNHG Display Pro below 28px. Tabular numerals for data. Uppercase only for tiny labels.
