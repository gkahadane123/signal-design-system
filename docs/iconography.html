The brand ships one icon set, and it replaces any third-party set. Do not substitute Lucide, Heroicons or hand-drawn glyphs: the set exists so that every product speaks with the same marks.

Browse the set

Search by name or tag, filter by category, and click an icon to copy its name.

How the icons are built

  • Grid: 96px, with a 3px stroke, round caps and joins, and a 2px content margin.
  • Two colors only: Ink (#4D4F5C, emitted as currentColor) carries structure. Coral (#FF6666) marks the icon’s subject, the thing it is about, never decoration. The accent dot is 7.5px, five times the stroke.
  • No third color. A mono variant collapses the accent into currentColor.

Size floor: 48px

Use 48, 64 or 96px. A 3px stroke on a 96px grid renders at 0.75px at 24px and falls apart, so the set has a hard floor of 48px. Smaller sizes need a separately drawn tier rather than a scale-down.

Do

Use icons at 48, 64 or 96px.

Don’t

Scale an icon down to 24px, or recolor it with a third color.

Using an icon

<Icon name="shield-check" title="Verified" />   // 48px, ink + coral accent
<Icon name="analytics-growth" size={64} />
<Icon name="package-scan" mono />               // single color
<Icon name="arrows-exchange" accent="var(--aqua)" />

Or use the SVG directly: assets/icons/<name>.svg. Icon names are still provisional while the source review sheet is signed off, so pin to a version if you depend on one.
