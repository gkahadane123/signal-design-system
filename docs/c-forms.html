Buttons and the form controls.

Button

Standard action button — pill-rounded; coral is reserved for THE primary action; everything else is ghost.

<Button onClick={go}>Request a demo</Button>
<Button variant="ghost">Explore the platform</Button>

Primary uses a white label on coral (--text-on-coral — important brand rule; keep labels ≥14px medium). Ghost is brand-white (Surface #FCFBF8) with Ink label on light AND dark backgrounds. Hover darkens via an ink overlay. Sizes sm/md/lg. Labels are sentence case, never uppercase.

Props

PropTypeDescription
variant?"primary" | "ghost""primary" (coral fill, one per view) or "ghost" (brand-white fill)
size?"sm" | "md" | "lg"
disabled?boolean
onDark?booleandeprecated — ghost is brand-white on every background now; kept for compatibility
children?React.ReactNode
onClick?() => void
style?React.CSSProperties

Input

Labeled text input, 8px radius, hairline border, Aqua focus ring.

<Input label="Work email" placeholder="you@company.com" hint="We reply within one business day" />
<Input label="Markets" error="Enter at least one market" />

Error state pairs a small warning glyph with Ink text (never color alone). Pass any native input props (type, value, onChange…).

Props

PropTypeDescription
label?string
hint?stringmuted helper line below
error?stringreplaces hint; icon + Ink text, coral used only as the icon fill cue
style?React.CSSProperties
inputStyle?React.CSSProperties

Select

<Select label="Market" options={["United States","United Kingdom","India"]} value={m} onChange={e=>setM(e.target.value)} />

Options may be strings or {value,label}.
