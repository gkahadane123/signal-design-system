The components are small, unopinionated primitives. Everything about their look comes from the tokens, so changing a token changes every component. Each has a TypeScript props contract and a short usage note, both shown on the group pages below.

Spec-defined and added

Button, Input, Card and Tag follow the brand specification directly. Select, Checkbox, Radio, Switch, Tabs, Dialog, Toast and Tooltip were authored around them. Four components are brand-specific additions:

  • Logo picks the correct lockup variant, color or white.
  • LineGrid is the 32px grid substrate, with optional pulses and technical framing. It is the core brand motif.
  • GradientTile places the coded gradients as tiles with a theme label.
  • Stat shows a large verified number with a mandatory source line.
