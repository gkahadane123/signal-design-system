Signal is plain CSS custom properties plus a small set of React primitives. There is nothing to compile to use the tokens.

Link the stylesheet

styles.css is the only stylesheet you link. It imports everything in tokens/.

<link rel="stylesheet" href="signal-design-system/styles.css">

/* or, from CSS */
@import "signal-design-system/styles.css";
FileDefines
tokens/colors.cssThe eight colors, opacity tints and semantic aliases such as --bg and --text-on-coral.
tokens/typography.cssThe type scale, tracking and leading, plus .t-display-1 through .t-label.
tokens/spacing.cssThe 8px rhythm, the 32px grid unit and container widths.
tokens/effects.cssRadii, shadows, easing and durations.
tokens/gradients.cssThe six .sig-grad-* classes, grain included.
tokens/icons.cssIcon ink and accent variables.
tokens/fonts.cssThe @font-face rules for NHG Display Pro.
tokens/base.cssBody, link, selection and focus defaults.

Add the fonts

Neue Haas Grotesk Display Pro is a licensed typeface, so the font files are not in this repository. Put your licensed copies in fonts/ using the filenames listed in fonts/README.md. Without them the stack falls back to Inter, which is why this site renders in Inter.

Use the tokens

.cta {
  background: var(--coral);
  color: var(--text-on-coral);   /* white, always */
  border-radius: var(--radius-btn);
  padding: 0 var(--space-5);
}

.card {
  background: var(--surface);
  border: 1px solid var(--border-hairline);
  border-radius: var(--radius-card);
  box-shadow: var(--shadow-card);
}

Use the React primitives

The components are compiled into _ds_bundle.js, which exposes them on window.SignalDesignSystem_167090. The website kit is built this way.

<link rel="stylesheet" href="signal-design-system/styles.css">
<script src="https://unpkg.com/react@18.3.1/umd/react.development.js"></script>
<script src="https://unpkg.com/react-dom@18.3.1/umd/react-dom.development.js"></script>
<script src="signal-design-system/_ds_bundle.js"></script>

<script>
  const { Button, Input, Tag } = window.SignalDesignSystem_167090;
  // <Button>Request a demo</Button>
</script>

Every component has its own page with props and examples: Components.

Use it with an AI agent

The repository root contains SKILL.md, which packages the system as an agent skill. Copy the folder into your skills directory and an agent can read the guidelines and build on-brand screens without being told the rules each time.
