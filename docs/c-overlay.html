Dialogs, toasts and tooltips.

Dialog

Modal on an ink scrim; footer holds the primary action.

<Dialog open={open} title="Request a demo" onClose={close}
  footer={<><Button variant="ghost" onClick={close}>Cancel</Button><Button onClick={send}>Send request</Button></>}>
  <Input label="Work email" />
</Dialog>

Props

PropTypeDescription
openboolean
title?React.ReactNode
onClose?() => void
footer?React.ReactNodeaction row, right-aligned — put the single primary Button here
width?number | string
children?React.ReactNode

Toast

Ink toast with signal dot.

<Toast tone="signal" message="Price change detected" detail="Refreshed 10 seconds ago" onDismiss={hide} />

Position it yourself (usually fixed bottom-right).

Props

PropTypeDescription
messageReact.ReactNode
detail?React.ReactNode
tone?"neutral" | "signal" | "coral"
onDismiss?() => void
style?React.CSSProperties

Tooltip

Small ink tooltip on hover/focus.

<Tooltip content="Exact-match false positives only"><Tag tone="signal">99% accuracy</Tag></Tooltip>

Props

PropTypeDescription
contentReact.ReactNode
side?"top" | "bottom" | "left" | "right"
children?React.ReactNode
style?React.CSSProperties
