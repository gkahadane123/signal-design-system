# Fonts

Signal uses **Neue Haas Grotesk Display Pro**, a commercially licensed typeface (Monotype).
The font files are **not** included in this repository.

Place your licensed copies here, using these names (referenced by `tokens/fonts.css`):

- `NHaasGroteskDSPro-35XLt.otf`
- `NHaasGroteskDSPro-45Lt.otf`
- `NHaasGroteskDSPro-55Rg.otf`
- `NHaasGroteskDSPro-65Md.otf`
- `NHaasGroteskDSPro-75Bd.otf`
- `NHaasGroteskDSPro-95Blk.otf`

Without them, the fallback stack (Inter → Arial/Helvetica) applies.
